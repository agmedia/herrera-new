# Herrera primary category photography

Created 2026-10-07 with the built-in `image_gen.imagegen` tool. Seven separate assets use the existing Herrera category images as motif references. The generated lighting image is the shared photographic style reference for the remaining six assets. These images illustrate category types; they do not identify a specific SKU or claim a manufacturer's product.

The series uses a square commercial/editorial photograph composition, warm-grey plaster, a neutral limestone surface, soft daylight from upper left, restrained natural colours and real contact shadows. No brands or readable captions were requested. All input photographs were inspected before generation.

Original PNGs are preserved unchanged under `originals/`. Browser versions are 768 × 768 progressive JPEGs, resized with Lanczos and encoded at quality 88; no content editing was performed during optimization. The original built-in output files remain at the returned paths recorded in the metadata.
