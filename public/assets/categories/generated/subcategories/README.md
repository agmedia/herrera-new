# Herrera subcategory photography

Created on 2026-10-14 using the built-in `image_gen.imagegen` tool, one separate identity-preserving edit per populated subcategory. The catalog has 425 subcategories at depths 1–3; 420 have active catalog products and five are empty. Empty subcategories are hidden from the carousel, sidebar and catalog menu. The existing primary-category photographs are preserved.

Art direction follows `../elektromaterijal-v1.jpg`: warm pale-grey plaster, a neutral limestone surface, soft window daylight from upper left, subtle window shadows, restrained natural colours and tactile materials. Every image uses the original photograph(s) of actual active products assigned to that category or its descendants, with product identity constraints. Real packaging is retained where it is the only product reference; nonphysical marketing overlays are removed. No generic or invented replacement product types are used.

Web assets are 512 × 512 progressive JPEGs, quality 87, resized with Lanczos. Only format conversion and resizing are applied. Original generated PNGs remain at the returned source paths recorded in the metadata. No text, labels, people, hands, watermarks or logos were requested.

`metadata-lighting-actual.json`, `metadata-electrical-actual.json`, `metadata-other-actual.json` and `metadata-additional-actual.json` record the exact final prompt, category, product IDs/SKUs/names, original product image URLs, local reference paths, generated source path and final web path for every asset. The prompts include the complete category ancestry and the exact catalog product descriptions. Early generic drafts were removed from public assets when actual-product fidelity was clarified; only actual-product edits are shipped.

`metadata-all-subcategories.json` is the final consolidated manifest: all 420 populated subcategories, the five hidden empty subcategories, final corrected source records and web file sizes. Completion checks found no missing or duplicate images, no broken mapping and no invalid JPEG. Every referenced product was verified active and assigned to the corresponding category or a descendant (387 distinct actual products). All web images together total approximately 21.94 MiB; only visible/lazy carousel images are requested by the browser.

The slug mapping is in `config/herrera-category-photography.php`. `HerreraCategoryImage` resolves these photographs at every category depth and across storefront locales. Uploaded category media takes precedence. A missing file safely uses the existing category image.

Category pages display their populated visible immediate children in a compact carousel below the title, with connected straight-edged blocks, flush 10:9 photographs and names linking to each child category. Product presence includes deeper descendants and follows catalog visibility. Counts are loaded in one grouped query shared by the carousel and sidebar; menu presence and translated photo slugs are also batched and use the existing navigation cache. Leaf categories have no empty carousel. Desktop and mobile category filters include a link back to the immediate parent. The carousel has native horizontal scrolling, keyboard navigation and small square arrow controls; no carousel dependency was added.
